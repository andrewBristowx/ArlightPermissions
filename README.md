# ArlightPermissions 1.0.1

Primer panel central visual para administrar LuckPerms y las funciones Arlight.

## Incluye
- `/permisos` exclusivo para `arlightpermissions.admin`.
- Panel personalizado en ArlightChatClient 3.8.0, no una cuadrícula de cofres.
- Categorías configurables: emotes, pases, cosméticos y minijuegos.
- Objetivos por rango o jugador específico.
- Permitir, negar, limpiar y dar temporalmente.
- Búsqueda de usuarios desconectados mediante LuckPerms.
- Registro `plugins/ArlightPermissions/audit.log`.
- Menú de inventario únicamente como respaldo si falta el cliente.

## Instalación
1. Compila con Java 21: `mvn clean package`.
2. Coloca el JAR en `plugins/` junto con LuckPerms.
3. Usa ArlightChatClient 3.8.0 en el cliente.
4. Reinicia y ejecuta `/permisos`.
